# A+ Content for the TinyTusk Learning Series

Images for **KDP → Marketing → A+ Content → Start creating A+ Content** (English). Built by `python3 brand/aplus.py`
from the books' own covers, pages and art (no new artwork); `brand/build_series.sh` re-runs it at the end.
Logos come from `brand/aplus/logos/` (Sima's horizontal, stacked, badge and mascot files, white made transparent).

| Folder | What's in it |
|---|---|
| `TinyTusk-ABC-Letter-Tracing-Workbook/aplus/` | 4 images for that book |
| `Trace-and-Write-the-Alphabet/aplus/` | 4 images for that book |
| `TinyTusk-A-to-Z-Animals-Color-by-Number/aplus/` | 4 images for that book |
| `brand/aplus/` | shared: logo, two series banners, comparison-chart covers |

## Module order (same for each book)

| # | A+ module | Image | Alt text (image keywords) |
|---|---|---|---|
| 1 | Standard Company Logo | `brand/aplus/logo_600x180.jpg` | TinyTusk Learning Series logo with a baby elephant |
| 2 | Standard Image Header with Text | `<book>/aplus/01_header_970x600.jpg` | Front cover of the book with its main features and age range |
| 3 | Standard Image Header with Text | `<book>/aplus/02_whats_inside_970x600.jpg` | Four inside pages of the book with labels |
| 4 | Standard Image Header with Text | `<book>/aplus/03_sample_pages_970x600.jpg` | A full inside page and two close-ups of its details |
| 5 | Standard Image Header with Text | `<book>/aplus/04_skills_970x600.jpg` | Four skills the book practises, each with a page example |
| 6 | Standard Comparison Chart | `brand/aplus/compare_<book>_150x300.jpg` (all four) | Front cover of each TinyTusk book |
| 7 | Standard Image & Light Text Overlay | `brand/aplus/series_banner_970x300.jpg` | The four TinyTusk Learning Series books with the elephant mascot |

`series_banner_970x600.jpg` is the same banner at 970 × 600, for a Standard Image Header with Text module instead
of the overlay module. The images carry their message, so module text can stay short or empty.
Comparison chart columns: `compare_az-coloring`, `compare_abc-tracing`, `compare_trace-write`, `compare_color-by-number`.

## Sizes
970 × 600 (Standard Image Header with Text), 970 × 300 (Standard Image & Text Overlay), 600 × 180 (Standard Company
Logo), 150 × 300 (Standard Comparison Chart). JPEG, all under 200 KB.

## A+ rules kept
No prices, discounts, reviews or star ratings, "best"/"#1", "new"/"now available", links, contact details, or
"buy now" style wording. Keep it that way when editing.
